# 📅 Time Table Schedule

A premium, responsive MCA weekly timetable designed with a modern 3D interface. It displays class schedules, subject timings, and dedicated tea and lunch break columns in a clean, organised layout.

## ✨ Features

- **Premium 3D Design** – Modern dark theme with depth effects and layered shadows.
- **Weekly Timetable** – Displays the MCA class schedule in a structured table.
- **Separate Break Columns** – Tea break and lunch break are displayed as continuous merged columns.
- **Vertical Break Labels** – Break names are displayed vertically for a clean layout.
- **Interactive Hover Effects** – 3D hover animations on timetable cells.
- **Responsive Layout** – Supports desktop, tablet, and mobile screens.
- **Subject Highlights** – Distinct colours for selected subjects.
- **Clean Interface** – Improved typography, spacing, and visual hierarchy.
